# Order Cancellation and Order Changes

## 1. Can I Cancel My Order?

| Order Status | Cancellation Possible? |
|---|---|
| Order Placed / Confirmed | ✅ Yes — cancel from My Orders |
| Packed / Being Processed | ✅ Usually yes — cancel from My Orders or contact support |
| Dispatched / Shipped | ❌ No — cannot cancel; may return after delivery |
| Out for Delivery | ❌ No — must receive and then return |
| Delivered | ❌ No — use the return process instead |

**Default rule**: Cancellation is possible **before the order is dispatched**. Once it ships, it cannot be cancelled.

## 2. How to Cancel an Order

**Self-service (recommended):**
1. Go to **My Orders** in the EasyBuy app.
2. Select the order.
3. Tap **Cancel Order** (or **Cancel Item** for multi-item orders).
4. Select the reason and confirm.

**Via support:**
1. Ask the customer for their Order ID and the item they want to cancel.
2. Verify the current order status in the backend.
3. If still cancellable: process the cancellation through the backend tool.
4. Confirm: "Your order has been successfully cancelled. Your refund of ₹[amount] will be processed within 24 hours."
5. If not cancellable (already dispatched): "Unfortunately, your order has already shipped and can't be cancelled at this stage. Once delivered, you can raise a return request within 7 days."

**Never claim cancellation succeeded without backend confirmation.**

## 3. Refund After Cancellation

| Cancellation Timing | Refund Timeline |
|---|---|
| Before dispatch | Initiated within 24 hours |
| After dispatch, before delivery | Initiated after item returns to warehouse (3–7 business days) |
| After delivery (return process) | Initiated after return pickup + inspection (3–5 business days) |

Refund returns to the original payment method (see doc 03 for details by payment type).

## 4. Partial Cancellation (Multi-Item Orders)

- If items in a multi-item order are shipped separately, each item can often be cancelled independently.
- Go to My Orders → select the specific item → Cancel Item.
- If shipped together: the entire shipment must be handled together.
- If one item needs to be kept and one cancelled: contact support to check if per-item cancellation is possible for that order.

## 5. Changing an Order (Size, Color, Quantity, Product)

Order modifications after placement are **not guaranteed**.

| Change Type | Typically Possible? |
|---|---|
| Delivery address | ✅ Before dispatch only |
| Quantity increase | ❌ Place a new order |
| Quantity decrease | ✅ Cancel the item and re-order if needed |
| Size / color change | ❌ Cancel and re-order (if cancellable) |
| Change to a different product | ❌ Cancel and place a new order |

**Best advice:** "Since modifying an order after placement isn't supported, the easiest option is to cancel this order (if it hasn't shipped) and place a new one with the correct details."

## 6. Cancellation After Dispatch

If a customer wants to cancel an already-dispatched order:

1. Acknowledge the request empathetically.
2. Check the current status — confirm the order is dispatched.
3. Explain: "Your order has already been dispatched and can't be cancelled at this point. However, once it's delivered, you have a 7-day window to return it for a full refund."
4. Optionally: "If you'd like, I can make a note on your account to remind you to raise a return request as soon as it arrives."

Do not promise an interception or redirect of the shipment unless the system supports it.

## 7. Cancellation Disputes

If a customer says they cancelled but the order still shows as active:

1. Check cancellation records in the backend — confirm whether a cancellation request was received.
2. If a request was received but not processed: escalate as a system issue (HIGH priority).
3. If no cancellation request is in the system: ask the customer when and how they cancelled (app / website / support call).
4. If the order has already shipped despite a cancellation request that was submitted before dispatch: this is an error — escalate urgently and initiate a return + full refund once delivered.

## 8. Escalation Conditions

Escalate when:
- Customer submitted a cancellation before dispatch, but the order shipped anyway
- Cancellation succeeded but refund hasn't appeared after 5+ business days
- Customer wants to cancel a partial item from a bundle/set
- An order change is needed that the system doesn't support
- Customer is in distress about an urgent cancellation (e.g., ordered wrong item for a gift)

## 9. Quick Reference Answers

| Question | Answer |
|---|---|
| Can I cancel after it's shipped? | No. Once dispatched, you'll need to return it after delivery. |
| When will I get my refund after cancelling? | Within 24 hours of cancellation (if cancelled before dispatch). |
| I cancelled but the order is still coming? | Contact us right away with your Order ID — this may be a processing delay or an error we need to investigate. |
| Can I change the size of what I ordered? | Size changes aren't supported. Cancel the order (if not yet shipped) and place a new one. |
| Can I cancel just one item from my order? | Yes, usually — go to My Orders and look for a per-item cancel option, or contact support. |
