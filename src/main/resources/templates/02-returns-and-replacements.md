# Returns and Replacements Policy

## 1. Standard Return Window

EasyBuy's standard return window is **7 calendar days from the delivery date**.

- The window starts the day the item is marked as delivered.
- After 7 days, standard return eligibility expires — though defect-based claims may still qualify under warranty (see doc 05).
- Some product categories have shorter or zero return windows (see Section 2).
- Return eligibility is product-specific and must be confirmed through the order/backend system.

## 2. Category-Specific Eligibility

| Category | Return Policy |
|---|---|
| Electronics | Returnable within 7 days; defects after 7 days handled under warranty |
| Clothing & Apparel | Returnable within 7 days; must be unworn, unwashed, with tags attached |
| Footwear | Returnable within 7 days; must be unused and in original packaging |
| Innerwear / Lingerie | Generally non-returnable for hygiene reasons unless item is defective |
| Beauty & Personal Care | Sealed/unopened: returnable; opened/used: not returnable unless defective |
| Books | Non-returnable unless wrong book was delivered |
| Grocery / Perishables | Not eligible for return; raise an issue immediately if item is spoilt or incorrect |
| Furniture / Large Appliances | Contactless inspection at delivery; damage must be reported before accepting |

When in doubt: check the product listing page for item-specific return terms.

## 3. Requesting a Return

**Step-by-step:**
1. Verify the customer's identity and that the order is within the return window.
2. Ask for the reason for return (wrong product, damaged, defective, changed mind, etc.).
3. Check the item's category and confirm eligibility.
4. If eligible: initiate the return request through the backend system.
5. Confirm only after the backend creates the return request — share the return request ID.
6. Explain pickup: "Our logistics partner will come to pick up the item within 2–5 business days. Please keep the original packaging ready."

**Never** say the return has been created until the backend confirms it.

## 4. Damaged or Wrong Product Received

This is treated as a high-priority issue.

1. Apologize sincerely and immediately.
2. Ask the customer to describe the damage or how the product differs from what was ordered.
3. Ask if they have photos — while not always mandatory, photos help speed up the resolution.
4. Check whether the issue can be resolved as a return or replacement.
5. If within 7 days: initiate a return/replacement request.
6. If after 7 days: check if a warranty or seller escalation path applies.

**Say:** "I'm really sorry about this! Receiving a damaged/wrong item is absolutely not okay. Let me get this resolved for you right away."

Do not guarantee a replacement or refund before the claim is assessed — but be reassuring that it will be resolved.

## 5. Replacement vs. Refund

- **Replacement**: Available for damaged, wrong, or defective products if the same item is in stock.
- **Refund**: Offered when replacement stock is unavailable, or when the customer prefers a refund.
- Customer's preference is taken into account — ask: "Would you prefer a replacement or a refund?"
- Refund processing: 3–5 business days after the return is received and inspected.

## 6. Return Outside the 7-Day Window

If a customer raises a return request after 7 days:

1. Check the exact delivery date and the date of the request.
2. If only 1–2 days over: apply empathy — "I understand it's just slightly past the standard window. Let me check if we can make an exception given the circumstances."
3. If defect is claimed: check if the issue falls under warranty rather than return policy (see doc 05).
4. If no exception or warranty path exists: escalate to a senior support agent for review.

Do not flatly deny without checking available options first.

## 7. Used, Opened, or Partially Used Products

- A product that has been used can still be returned if it arrived defective or damaged — do not reject this automatically.
- Changed-mind returns on used products are generally not accepted.
- For electronics: if the item was used but a defect appeared after a few uses, it likely falls under warranty.

## 8. Return Pickup

- Pickup is typically arranged within 2–5 business days after return approval.
- Customer must have the item in original packaging (or as-close-to-original as possible).
- If the customer cannot be home for pickup: advise them to use the "Reschedule Pickup" option in the app, or contact the logistics partner using the provided contact number.

## 9. Escalation Conditions

Escalate when:
- Product is damaged and customer is requesting urgent resolution
- Customer received a completely wrong product
- Return request was placed but pickup was never arranged after 5 business days
- Category-specific rules are ambiguous for the specific product
- Customer is requesting an exception beyond the 7-day window
- Return was picked up but refund has not been processed after 7+ business days

## 10. Quick Reference Answers

| Question | Answer |
|---|---|
| What is the return window? | 7 calendar days from delivery. |
